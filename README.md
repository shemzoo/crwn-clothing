🛍️ eCommerce App

A modern clothing eCommerce web application built with React.
Browse stylish outfits, manage your shopping cart, and complete secure test payments through Stripe.

🚀 Features

Product Catalog — View a curated list of clothing items sorted by categories.

Category Navigation — Explore items within each category.

Cart Management — Add products to your cart, update quantities, or remove items.

Stripe Payments — Test checkout flow with a demo credit card (no real transactions).
